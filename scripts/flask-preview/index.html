Ducat · Local development

See it inside Flask.

Connect the local Ducat Snap, approve its permissions in MetaMask Flask, then open Ducat’s Home screen.

Use the browser profile where MetaMask Flask is installed.

Ready to view.

In Flask, open Snaps → Ducat. To pick up a rebuilt version, use Reconnect local build.

This build uses native Snap components for Home and Settings, with real BTC, UNIT, ETH, wUNIT, and USDC balances. Flask supplies the fonts, colors and input styles. BTC pricing and an estimated total are connected. UNIT, wUNIT and USDC use a $1 reference; testnet estimates are illustrative. ETH in the wallet row uses your permitted MetaMask account. Ducat automatically uses the permitted MetaMask account when Home opens. MetaMask may ask to share an account on the first opening; there is no separate ETH Connect button. Testnet reads Sepolia; Mainnet reads Ethereum. wUNIT is currently configured on Sepolia; on Mainnet its row says Available on Testnet. Available asset valuations contribute to the estimated total.

Values start as plain text. Use a chevron to reveal the native copy field inline. Expanded addresses fill the entire BTC/UNIT/ETH row; collapse to restore all three columns. URL edits retain network validation; the key pencil opens an inline private-key editor inside Settings.
