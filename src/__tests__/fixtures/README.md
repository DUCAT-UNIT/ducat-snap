# Vault action samples

`vault-actions.json` contains unsigned PSBT packages generated by the actual client-sdk API builders, plus public synthetic prevouts and protocol data. It covers deposit, withdraw, borrow, partial repay with BTC returned, full repay, and open. Inputs are deterministic test coins; oracle signatures are placeholders. These are display/ownership fixtures, not transactions for broadcasting or oracle-validation tests.

The tests pass these bytes through `preparePsbtForSigning`, the full previous-output verifier, and the real confirmation builder. They do not fabricate the final summary. Taproot vectors are independently produced by the SDK, including odd leaf counts and multiple guardians.

Expected package sizes: deposit/withdraw 1; open/borrow/repay 2. Each example pays a total 500-sat network fee. Protocol reserve: 1,000 sats. UNIT divisibility: 2. Before values come from the fixture's prior transaction. A withdrawal pays 1,000,000 sats to the wallet and reduces collateral by 1,000,500 sats. The partial repayment returns both released collateral and funding change to the wallet.
